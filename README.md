# IoT_PBLParkingLotSystem
IoT Parking Availability System

This code allows the user to determine whether or not there is a parking spot that is available.

Material Used:
  - Arduino UNO board
  - Ultrasonic sensor
  - RGB LED light
  - 220 ohms resistor (x3)

Pinouts:
  - Ultrasonic sensor:
      - TRIG pin to digital pin 10
      - ECHO pin digital pin 11
      - VCC pin to 5V
      - GND pin to GND
  - RGB LED:
      - Red leg to 220Ω resistor to digital pin 3
      - GND pin to GND
      - Green leg to 220Ω resistor to digital pin 5
      - Blue leg to 220Ω resistor to digital pin 4
